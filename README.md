# Meta Física
Aplicativo para controle de alimentação, treinos e acompanhamento de resultados físicos.

## Funcionalidades
✅ Registro de refeições
✅ Agenda de treinos: corrida, vôlei, exercícios em casa
✅ Acompanhamento de peso
✅ Gráfico de evolução
✅ Lembretes de água
✅ Frases de motivação

## Resultado vem com disciplina, não com sorte.
